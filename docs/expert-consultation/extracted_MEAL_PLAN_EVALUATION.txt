APPENDIX X. Evaluation of Generated Meal Plans
Purpose
Dear Registered Nutritionist-Dietitian, this packet presents representative meal plans generated by PCOSina for professional evaluation. The purpose is to assess nutritional appropriateness, serving realism, meal completeness, cultural suitability, and budget reasonableness for the stated user profiles.
PCOSina is a wellness decision-support application. It does not diagnose, treat, prescribe, or replace individualized medical nutrition therapy. Your professional comments will be used as validation evidence and as guidance for improving the meal-planning dataset and output format.
Important Reading Note on Ingredients and Cost
Some recipe ingredient lists come from original recipe sources and may describe the full batch recipe, such as a dish cooked with several pounds of meat. The planned meal slot represents one person/serving, not necessarily the entire batch recipe.
To avoid confusion, each scenario now includes a cost-basis table. The table separates the original batch/catalog estimate from the estimated cost per planned serving. When a recipe has source serving or yield metadata, the system divides the batch estimate by the source serving count. When no source serving count is available, the item is treated as one planned serving from the curated quick-meal catalog.
The cost values are planning estimates based on the PCOSina pricing audit catalog. Actual prices may vary by location, store, brand, package size, season, and current market conditions.
Nutrition and Reference Basis
Nutrition values are taken from the PCOSina reviewed runtime nutrition dataset used by the application during meal generation. These values are traceable within the system, but some are source-verified while others remain draft estimates requiring professional validation.
The Philippine Food Composition Tables (PhilFCT/DOST-FNRI) are acknowledged as the preferred local reference for future ingredient-level verification and correction. Full PhilFCT integration is a recommended improvement, not a completed claim in this prototype version.
Macronutrient targets are evaluated at the whole-day and whole-week level, not as a requirement that every individual recipe independently matches the same percentage distribution.
Professional target noted from consultation: approximately 1,800 kcal/day, 225 g carbohydrates, 90 g protein, 60 g fat, and 25-30 g fiber/day for whole-day evaluation, subject to individualization by profile and clinical judgment.
Nutrition Data Source and Current Limitation
For transparency, the current prototype does not yet use a fully integrated Philippine Food Composition Tables (PhilFCT) runtime database for all recipes. The generated nutrition values come from the PCOSina reviewed runtime nutrition dataset used by the application during meal generation.
This dataset contains mixed nutrition sources: source-verified recipe-card values where available, source-yield-normalized recipe-card values where source servings are available, local/reference ingredient-sum draft estimates, and seed-file estimates for curated quick meals.
Values marked as api_estimate are not random or AI-generated final values. They are draft estimates produced through ingredient matching and summation against food composition references, primarily USDA FoodData Central-style records and local reference ingredient profiles, then divided by source serving/yield when available.
Because these estimates remain draft values, they are labeled pending_review or needs_review. They are suitable for prototype testing and structured expert review, but they should not be treated as final clinical nutrition values without professional validation.
Based on your recommendation, PhilFCT/DOST-FNRI is documented as the preferred primary reference for future ingredient-level correction and validation. Full PhilFCT integration is therefore listed as a limitation and recommended improvement of the current prototype.
Meal Completeness Note
Some catalog entries are one-dish meals or recipe dishes. Please evaluate whether a meal is complete by itself or should be paired with an additional side, vegetable, fruit, or carbohydrate adjustment according to Pinggang Pinoy principles and your professional judgment.
If a meal is acceptable only with portion adjustment or side-dish pairing, kindly indicate that in the remarks so the researchers can document the required improvement.

Current Limitations and Recommended Improvements
The researchers acknowledge the following limitations for this evaluation version:
1. The runtime nutrition database is not yet fully PhilFCT-based. PhilFCT/DOST-FNRI should be used as the preferred reference for future ingredient-level correction.
2. Some recipe ingredient lists show original batch quantities, while the planned meal slot represents one serving/person. The cost table is included to clarify batch cost versus planned serving cost.
3. Some generated meals may require side dishes, portion adjustment, fruit, vegetable, or carbohydrate pairing to better satisfy Pinggang Pinoy meal completeness.
4. Nutrition values marked as api_estimate, pending_review, or needs_review should be treated as draft values until validated by a Registered Nutritionist-Dietitian or corrected against a stronger reference.
5. The system is intended for wellness decision support and academic prototype validation. It should not be used as a substitute for individualized medical nutrition therapy.
