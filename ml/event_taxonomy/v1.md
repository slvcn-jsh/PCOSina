# ML Event Taxonomy v1.1

Schema file: `shared-contracts/event_schemas/ml_event_taxonomy.v1.json`

## Common required fields
- `event_id`
- `event_name`
- `event_time_ms`
- `uid_hash`
- `request_id`
- `policy_version`

## Planner pipeline events
1. `plan_generation_requested`
- Required: `days`, `meals_per_day`

2. `stage1_candidates_scored`
- Required: `candidate_count_pre`, `candidate_count_post`, `ranking_strategy`, `ml_score_enabled`, `ml_model_version`

3. `solver_completed`
- Required: `status`, `runtime_ms`, `reason_codes`

4. `async_solver_completed`
- Required: `status`, `runtime_ms`, `reason_codes`

## Product behavior events (required by ML roadmap)
1. `plan_generated`
- Required: `status`, `plan_id`, `slot_count`

2. `plan_viewed`
- Required: `plan_id`

3. `meal_accepted`
- Required: `plan_id`, `slot_index`, `recipe_id`

4. `meal_replaced`
- Required: `plan_id`, `slot_index`, `old_recipe_id`, `new_recipe_id`

5. `meal_skipped`
- Required: `plan_id`, `slot_index`, `recipe_id`

6. `recipe_opened`
- Required: `recipe_id`

7. `grocery_completed`
- Required: `plan_id`

8. `pantry_item_added`
- Required: `item_token`

9. `pantry_item_removed`
- Required: `item_token`

10. `pantry_item_expired`
- Required: `item_token`

11. `cook_completed`
- Required: `plan_id`, `recipe_id`

12. `no_safe_plan_encountered`
- Required: `reason_codes`

13. `manual_override_attempted`
- Required: `override_type`

14. `why_replaced_submitted`
- Required: `plan_id`, `slot_index`
- Optional input: `reason_tag`, `reason_tags`, `reason_text`
- Normalized output fields (backend):
  - `reason_primary_tag`
  - `reason_tags`
  - `reason_source` (`tag_only`, `text_only`, `tag_and_text`, `none`)
  - `reason_has_free_text`
  - `reason_text_hash` and `reason_text_length` (raw text not persisted)

15. `why_skipped_submitted`
- Required: `plan_id`, `slot_index`
- Optional input: `reason_tag`, `reason_tags`, `reason_text`
- Normalized output fields (backend): same as `why_replaced_submitted`

## Safety boundary
ML telemetry is non-authoritative. Event consumers cannot bypass Stage 2 CP-SAT hard-rule enforcement.
