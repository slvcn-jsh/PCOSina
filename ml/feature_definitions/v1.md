# Feature Definitions v1 (LightGBM Stage-1 Ranking)

## Training Label
- `selected_by_solver` (binary): 1 if candidate appears in authoritative final plan, else 0.
- Label source: `ml_stage1_candidate_features.selected_by_solver`, written after Stage 2 CP-SAT output.

## Feature Groups

### User/Profile Context
- `restriction_count`
- `allergy_count`
- `budget_weekly_norm`
- `max_cooking_time_minutes`
- `activity_level_bucket`
- `goal_bucket`

### Candidate Recipe
- `recipe_calories`
- `recipe_protein`
- `recipe_carbs`
- `recipe_fats`
- `recipe_fiber`
- `recipe_minutes`
- `recipe_cost_est`
- `protein_group`
- `is_breakfast_candidate`
- `is_lunch_candidate`
- `is_dinner_candidate`

### Contextual Fit
- `pantry_overlap_count`
- `macro_distance_score`
- `calorie_distance_score`
- `restriction_compatible` (must be 1 to enter stage1 shortlist)

### Ranking Metadata
- `model_score` (shadow/canary score)
- `heuristic_score` (baseline ranking score)
- `ranking_strategy`
- `model_version`

### Feedback Features (Optional)
- `replace_reason_tag_hist_*`
- `skip_reason_tag_hist_*`

## Inference Scope
Model score affects candidate ranking priority only. Stage-2 CP-SAT remains final decision authority.

## Cold-start behavior
- If model artifact or dependencies are unavailable, Stage 1 falls back to deterministic heuristic scoring.
