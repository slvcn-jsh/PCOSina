# PCOSINA Tester Instructions

PCOSINA is a wellness decision-support app for Filipino PCOS meal planning. It does not diagnose, treat, or replace medical advice.

## Install

1. Open the Firebase App Distribution invite from the research team.
2. Accept the invite using the email address that received it.
3. Install the Firebase App Tester app if prompted.
4. Install the latest PCOSINA staging build.

You do not need Android Studio, ADB, an emulator, wireless debugging, or Firebase App Check debug tokens.

## Test Flow

1. Open PCOSINA.
2. Sign in with Google.
3. Complete your profile, dietary preferences, allergies, pantry, and budget.
4. Generate a meal plan.
5. Review the Plan screen.
6. Review recipe details and swap options if available.
7. Open Grocery and confirm the grocery output appears.
8. Open Progress and log at least one meal or progress item.
9. Open Settings and confirm sign out works.
10. Open Support and report confusing output, crashes, or blockers.

## What To Report

Please report:
- Crashes or app freezes.
- Google Sign-In problems.
- Profile or onboarding confusion.
- Meal plan generation failures.
- Grocery list issues.
- Progress logging issues.
- Food suggestions that seem unsafe, impossible, or confusing.
- Any screen that shows raw technical errors.

Include:
- Phone model and Android version.
- Approximate time of issue.
- What you tapped before the issue happened.
- Screenshot if it is safe to share.

Do not share passwords, private medical records, or sensitive IDs in feedback.
